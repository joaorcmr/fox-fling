# Revoada Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tower defense 2D de porcos contra pássaros, jogável de ponta a ponta em 600×480, com 1 mapa, 30 ondas, 4 porcos com upgrades e especializações, Ninho de Penas, menu, sons e build WebGL.

**Architecture:** As regras e a simulação ficam em C# puro (assembly `Revoada.Nucleo`): classes sem MonoBehaviour, passo fixo de 1/60 s e eventos C#. Elas são testadas no EditMode e jogadas por robôs de balanceamento. A camada Unity (`Revoada`) avança a simulação no `FixedUpdate`, desenha com prefabs, SpriteRenderer, LineRenderer e ParticleSystem, ouve o mouse e mostra a interface em uGUI. Um construtor de Editor (`Revoada.Editor`) gera os dados (ScriptableObjects), os prefabs, as cenas e as configurações a partir do código, como no Fox Fling.

**Tech Stack:** Unity 6000.6.4f1 (Built-in RP), uGUI 2.6.0 (`Text` legado com a fonte embutida `LegacyRuntime.ttf`), Input Manager antigo, Unity Test Framework 1.8.0 (EditMode), Python 3 + Pillow para a arte, `wave` para os sons, `unity` CLI + pacote `com.unity.pipeline` para dirigir o Editor.

**Spec:** `docs/superpowers/specs/2026-11-07-revoada-design.md`

**Execução:** nativa nesta sessão. O João mandou começar a construir, acompanha pelo celular e recebe um print do Unity no fim das Tasks 4, 6, 8, 9 e 10.

## Global Constraints

- Unity 6000.6.4f1, Built-in RP, Input Manager antigo (`activeInputHandler: 0`), uGUI 2.6.0. Nenhum pacote novo.
- Resolução **600×480** no standalone e no WebGL (regra da disciplina). `productName` "Revoada", `companyName` "joaorcmr".
- 1 unidade = 32 px na tela. Câmera ortográfica com `orthographicSize = 7.5` em (9.375, 7.5, −10): o mundo vai de x = 0 a 18.75 e de y = 0 a 15. O mapa ocupa x ∈ [0, 14], y ∈ [0, 15]; a barra lateral (152 px) cobre x > 14.
- Sprites com 64 pixels por unidade (desenhados em 2× para ficarem nítidos), filtro bilinear, sem mipmap, sem compressão.
- Simulação com passo fixo `Simulacao.Dt = 1/60 s`, determinística, sem `UnityEngine.Random` e sem física. Do Unity ela usa só `Vector2` e `Mathf`.
- Ordem de desenho: chão abaixo de 0. Atores (pássaros, porcos, árvores, Torre) na ordem 0, ordenados por y pela câmera (`transparencySortMode = CustomAxis`, eixo (0, 1, 0)). Tiros 10, efeitos 20, barras de vida 30, fantasma de colocação 40.
- Textos do jogo em português, nenhum menor que 12 px. Comentários em português, explicando o porquê.
- Nome, personagens, mapa e nomes de upgrades são próprios: nada do BTD6 nem de Angry Birds.
- Pastas `Assets/Revoada/{Arte, Audio, Dados, Editor, Prefabs, Cenas, Scripts, Testes}`. Sem namespaces, como no Fox Fling.
- Git: tudo na branch `feat/revoada`, com os `.meta` gerados pelo Unity. Um commit por task. Push só com OK do João; a `main` só recebe a branch depois que ele aprovar o jogo.
- Testes: com o Editor fechado, `~/.unity/bin/unity test --mode EditMode --filter <Classe> --output Logs/testes.xml` na pasta do projeto (saída 0 = passou, 8 = algum teste falhou). Com o Editor aberto, rodar pelo comando de testes que o Pipeline lista em `unity command` e ler o relatório.
- Prints: captura da Game view pelo Pipeline, salva em `Screenshots/` (pasta ignorada pelo git), conferida e mandada ao João com SendUserFile. Se a tela do Mac estiver bloqueada e o Play parar de avançar, pausar e bombear `EditorApplication.Step()` com `Time.timeScale` alto (memória `unity-cli-tela-bloqueada`).

## Review Focus

- Um clique na barra lateral não pode colocar nem selecionar porco no mapa. `Controles` ignora cliques com `EventSystem.current.IsPointerOverGameObject()`, e `Colocacao.Valida` recusa x > 14 − raio (teste `ForaDoMapa_Invalido`, Task 5; conferido jogando na Task 6).
- Vender ou melhorar um porco com tiro no ar: o tiro continua com os atributos de quando saiu e nada quebra (testes `Vender_ComTiroNoAr_NaoQuebra`, Task 5, e `Melhoria_NaoMudaTiroNoAr`, Task 7).
- Na última onda, se um pássaro zera a vida da Torre no mesmo passo em que o último estoura, o resultado é derrota, não vitória (teste `MesmoPasso_DerrotaGanhaDaVitoria`, Task 3).
- Mira num alvo perto do fim da trilha: o ponto previsto fica no fim da trilha, sem NaN (teste `Antecipar_NoFimDaTrilha_Limita`, Task 5).
- Reiniciar ou voltar ao menu com o jogo pausado ou em 3× faz o `Time.timeScale` voltar a 1 (conferido na Task 8: pausar, ir ao menu de pausa, reiniciar e ver os pássaros andando).
